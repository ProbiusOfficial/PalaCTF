在线模拟

模拟平台完全在浏览器内运行，不连接后端，赛事、题目、队伍与排行榜数据均为虚构演示内容，不代表真实赛事或成绩。模拟身份无需注册，清除站点存储后恢复初始状态。

模拟平台仅用于预览界面与交互；真实使用请通过正式发布包私有化部署。

私有化部署

Linux 上使用 Docker Engine 和 PostgreSQL 部署。应用由单个可执行文件提供网页和 API。安装要求与校验方法随正式发布包提供。
