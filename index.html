平台能力

经典解题

题目、动态 Flag、排行榜、队伍与赛后复盘。

攻防模式

AWD 轮次、服务可用性检查和 AWDP 补丁验证。

题单、课程、知识库与个人学习进度。

私有化部署

Linux 上使用 Docker Engine 和 PostgreSQL 部署。应用由单个可执行文件提供网页和 API。安装要求与校验方法随正式发布包提供。

下载与许可

正式安装包通过 GitHub Releases 发布。请根据发布说明验证文件并阅读包内许可证。PalaCTF 是专有软件；公开介绍不授予源码或软件使用许可。
